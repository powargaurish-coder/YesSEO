# Mantra Audio Lab

Isolated test for Sanskrit mantra audio generation using the open-source `ai4bharat/indic-parler-tts` model via the VEXYL-TTS approach.

## Voice
- Language: Sanskrit (`sa-IN`)
- Female speaker: Vasudha
- Style: warm, calm, slightly slow, devotional
- Output: WAV

## Test batch
1. Vakratunda Mahakaya
2. Om Gam Ganapataye Namah
3. Om Namah Shivaya

The workflow runs only on the `mantra-audio-lab` branch and uploads WAV outputs as a GitHub Actions artifact. It does not alter or deploy anything from the main branch.
